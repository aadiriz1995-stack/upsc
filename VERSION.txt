Track2Crack v1.8 — Firebase Cloud Sync Release

Core change:
- Replaced Google Drive live database approach with Firebase Authentication + Cloud Firestore.
- Uses Email/Password login for easier setup.
- Data is stored per user at users/{uid}/app/state.
- Designed for phone, office PC and home PC access using the same hosted Firebase URL.

Included:
- Mission Control Dashboard
- Lectures Module
- Planner Engine
- Current Affairs Management
- Revision Engine
- AI Mentor workspace
- Analytics Dashboard
- Gamification System
- Settings Engine
- Firebase Cloud Sync controls
- JSON export/import backup
- Firebase Hosting config
- Firestore security rules

Limitations:
- PDF/screenshot/image upload binaries are not synced in v1.8. Structured records sync; file storage can be added later.
